# Prodigy_Task01_Authentication

Full-stack user authentication system built with the MERN stack and Tailwind CSS v4 as part of the **Prodigy InfoTech** Full-Stack Web Development Virtual Internship.

## Features
- **User Registration & Login:** Secure credential validation and account creation.
- **Password Hashing:** Passwords encrypted using `bcrypt` before database storage.
- **JWT Session Management:** Stateless authentication tokens issued on login and verified via Express middleware.
- **Protected Dashboard:** Role-based access control restricting unauthorized users from accessing `/dashboard`.
- **Modern Dark UI:** Responsive SaaS interface styled with React, Vite, React Router, and Tailwind CSS v4.

## Tech Stack
- **Frontend:** React, Vite, React Router, Tailwind CSS v4
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas (Mongoose)
- **Security:** `bcrypt`, `jsonwebtoken`, `dotenv`, `cors`
